# أذكار – Flutter Native

مشروع Flutter عربي (RTL) مبني كتطبيق Android Native، وليس WebView.

## ما يتضمنه
- 44 ذكراً مستخرجاً من ملف HTML المرفق (الصباح والمساء).
- عدادات تكرار مستقلة لكل ذكر، ومفضلة، وبحث.
- مسبحة بأهداف 33 و66 و99.
- الوضع الفاتح والداكن.
- مواقيت الصلاة لسطيف عبر واجهة AlAdhan مع تحديث يومي/يدوي.
- حفظ التقدم محلياً باستخدام SharedPreferences.

## بناء APK عبر GitHub Actions
1. أنشئ مستودع GitHub جديداً.
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع (لا ترفع المجلد الخارجي نفسه).
3. افتح تبويب Actions وفعّل workflows إذا طلب GitHub ذلك.
4. شغّل `Build Android APK` من Run workflow، أو ادفع commit إلى `main`.
5. بعد انتهاء البناء افتح تشغيل الـ workflow ثم Artifacts وحمّل `adhkar-release-apk`.

## ملاحظات شفافة
- هذا تحويل Native فعلي للوظائف الأساسية، وليس نسخاً آلياً لكل CSS/JavaScript. تمت إعادة بناء الشاشات والمكونات في Flutter.
- قسم القرآن في HTML يعتمد على أجزاء/مصادر ديناميكية غير موجودة كنص مصحف كامل داخل الملف؛ لذلك تعرض النسخة الحالية توضيحاً بدلاً من عرض محتوى ناقص.
- تبويب الأدعية كان فارغاً في HTML المرفق، لذا يظهر كقسم تمهيدي.
- مواقيت الصلاة تحتاج اتصال إنترنت لجلب مواقيت اليوم، وتستخدم إحداثيات سطيف وطريقة الحساب 3. تحقق من إعدادات الجهة الرسمية المحلية إذا أردت طريقة حساب مختلفة.
- workflow ينشئ مجلد Android القياسي بواسطة `flutter create` في بيئة GitHub، ثم يبني APK release ويرفعه كـ Artifact.

## تشغيل محلياً
```bash
flutter pub get
flutter run
```
